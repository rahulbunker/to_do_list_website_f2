# 📋 TaskFlow &mdash; Modern & Elegant To-Do List Website

A modern, responsive, offline-first personal productivity and task management web application. Built with clean HTML5, CSS3, and modern JavaScript.

---

## ✨ Features

- **Intuitive Task Management**:
  - Add tasks with title, rich notes/descriptions, due dates, priority levels, and category tags.
  - Interactive checklists / subtasks for each task with progress tracking.
  - Pin & Star important tasks to spotlight them at the top.
  - Strike-through completion with a synthesized Web Audio harmonic chime and canvas confetti celebration!
  - Delete tasks with an instant **Undo** toast notification.
  - Edit tasks directly in an interactive modal.

- **Organized Views & Filters**:
  - **All Tasks**: Complete overview with pinned tasks on top.
  - **Today**: Filter tasks scheduled for today.
  - **Upcoming**: Scheduled future tasks.
  - **Important**: Quickly view starred high-priority items.
  - **Completed**: Archive of accomplished tasks.
  - **Custom Categories**: Work, Personal, Study, Fitness, Shopping + create your own categories with custom color palettes.

- **Productivity Boosters**:
  - **Pomodoro Focus Timer**: Built-in 25-minute focus session with automatic 5-minute break cycle and audio bell.
  - **Live Search**: Instant real-time search across tasks, notes, and categories.
  - **Sorting**: Sort by Newest, Oldest, Due Date, Priority (Urgent &rarr; Low), or Alphabetical (A &rarr; Z).
  - **Daily Progress Bar**: Live visual feedback of your completed vs. total tasks.

- **Look & Feel**:
  - **Dark / Light Theme Toggle**: Seamless transition between high-contrast dark mode and clean light mode.
  - **Sound FX Toggle**: Switch on/off the task completion chime and timer sound effects.
  - **Fully Responsive**: Optimized for desktop, laptop, tablet, and mobile screens.

- **Data Safety & Portability**:
  - Automatically persists all your tasks, subtasks, categories, and preferences to browser `localStorage`.
  - **Export JSON**: Download a full backup of your tasks anytime.
  - **Import JSON**: Restore your data on any device or browser.

---

## 🚀 How to Run

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, Brave, etc.):

- **Windows**: Double-click `index.html` or run `start index.html` in PowerShell / Command Prompt.
- No Node.js, Python, or npm installation required. Everything works out of the box!
